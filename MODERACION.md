# Proceso de moderación

Lo aplica el responsable de la web, a mano. No hay moderación automática.

## Frecuencia

- Revisión de mensajes nuevos y avisos: al menos dos veces por semana.
- Datos personales publicados por error: se ocultan en cuanto se ven, como máximo en 48 horas.

## Qué se hace en cada caso

| Situación | Acción |
| --- | --- |
| Datos personales (DNI, IBAN, teléfono, documentos) | Editar el mensaje para quitarlos o ocultarlo, y avisar al autor. |
| Publicidad o enlaces de captación | Ocultar como *spam*. Si se repite, bloquear al usuario. |
| Insultos, acoso o amenazas | Ocultar como *abuse*. Bloquear al usuario si es grave o se repite. |
| Dato incorrecto (tipo de impuesto, norma, cifra) | No se borra: se responde con la fuente oficial y se corrige la guía de la web si también está mal. |
| Pregunta que se repite | Responder con el enlace a la guía o calculadora que la resuelve. Si no existe, anotarla como idea de guía. |

Un aviso por sí solo no basta para borrar un mensaje: se revisa antes.

## Herramientas de GitHub

- **Hide** en el mensaje (*spam*, *abuse*, *off-topic*, *outdated*, *duplicate*, *resolved*).
- **Block user** desde el perfil del usuario o los ajustes del repositorio.
- **Settings → Moderation options → Interaction limits** para limitar temporalmente quién puede escribir si hay una avalancha de spam.

## Qué no se hace

- No se inventan preguntas ni respuestas para dar sensación de actividad.
- No se editan opiniones de otros, salvo para quitar datos personales.
